# CreatorCircles Backend

Este projeto é o backend do CreatorCircles, desenvolvido em Node.js + TypeScript, integrado ao Sui via REST e GraphQL.

## Funcionalidades


## Como rodar localmente

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```
